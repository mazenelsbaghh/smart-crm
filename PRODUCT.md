# Product

## Register

product

## Users

Arabic-speaking support teams, sales staff, and project managers handling WhatsApp, Messenger and Facebook comments. They switch between desktop and phone, manage customers and bookings, and supervise automated replies and marketing.

## Product Purpose

A shared workspace for customer conversations, CRM, follow-ups, appointments, knowledge, content and advertising. Pages should reveal the next useful action without making operators memorize icons or search long settings forms.

## Brand Personality

Calm, direct and dependable. Clear Arabic text, clear teal actions, richer semantic colors and labeled icons, visible context and consistent controls support frequent daily work.

## Confirmed Direction

On 16 October 2026 the user selected the light visual direction, required mobile usability, and authorized implementation across the existing pages. This replaces the previous neon dark direction. Dark mode remains an optional preference. Later feedback on the same day explicitly requested richer colors, clearer UX and more icons; retain visible labels beside icons and use color to communicate role or state. A further authorized pass changes the navigation shape, consolidates shared components and follows a new AI-generated visual reference.

## Design Principles

1. Keep the workspace light, with an ink-colored navigation surface, teal actions and distinct semantic colors for status, context and AI.
2. Use one Arabic type family across navigation, forms, tables and conversations.
3. Organize navigation around daily work, growth and administration, with visible names.
4. Adapt structure for phones: list then details, compact headers and an anchored chat composer.
5. Reveal secondary controls progressively; keep operational safety, data freshness and error evidence visible.
6. Reuse shared controls and patterns. Preserve tenant boundaries, permissions, unsaved input and existing API behavior.

## Anti-references

- Icon-only navigation that hides entire sections.
- Neon glows, decorative motion, glass panels or oversized dashboard headings.
- Desktop tables squeezed into phone screens.
- Long explanatory blocks before the records users need.
- Forms whose floating controls cover the fields.

## Accessibility & Inclusion

Arabic RTL is the default document direction. Inputs, keyboard focus, reduced motion and mobile safe areas belong to the shared foundation. Statuses need readable labels as well as color. Verify contrast and touch targets in rendered screens rather than assuming a palette proves accessibility.
